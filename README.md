# Маршруты по барам и пабам ЮАО

Сайт: https://babajusik.github.io/uao-bars-routes/

Откройте сайт на телефоне или компьютере, укажите стартовый адрес и выберите найденную точку. Также можно использовать геопозицию, координаты или метку на карте. По умолчанию старт — ориентир в центре Видного.

Заведения выстраиваются по принципу «следующая ближайшая по автомобильной дороге». Список делится на участки по 19 новых заведений; последняя точка предыдущего участка становится стартом следующего. Каждый участок открывается в Яндекс Картах. Выбранный старт и отметки сохраняются в браузере на текущем устройстве.

В базе сохранены все 450 исходных заведений. По умолчанию показаны 135 целевых. Фильтры меняют состав и порядок объезда. Список текущих маршрутов можно скачать в отдельный HTML для телефона, а выбранные записи — в CSV.

## Как работает

- `index.html` — самостоятельная страница без сборки и серверной части.
- Матрица расстояний между заведениями встроена в страницу (OSRM / OpenStreetMap, расчёт 4 ноября 2026). При новом старте загружается только одна строка расстояний от старта до всех точек: пять последовательных запросов с интервалом не меньше 1,1 секунды. Она сохраняется локально вместе со стартом.
- Поиск адресов — [Photon](https://github.com/komoot/photon), по явному нажатию кнопки. Подсказки не запрашиваются при каждом вводимом символе.
- Автодороги — [OSRM / FOSSGIS](https://routing.openstreetmap.de/about.html), данные © [OpenStreetMap](https://www.openstreetmap.org/copyright). Маршруты рассчитываются без текущих пробок и без гарантии глобально кратчайшего объезда; Яндекс строит актуальный автопуть между переданными остановками.
- В Яндекс передаются координаты в формате `широта,долгота`. Максимум 20 точек с учётом старта: 19 новых остановок плюс начало участка.
- Если новый расчёт не удался, прежний старт и маршруты сохраняются. Сброс на Видное работает без запроса расстояний.

Для поиска адресов, карты и нового старта нужен интернет. Введённый адрес отправляется Photon, координаты расчёта — OSRM; ссылки и встроенная карта открываются в Яндексе. Последний выбранный старт хранится в `localStorage` этого браузера, в репозиторий он не записывается.

На iPhone сайт можно сохранить на домашний экран через меню «Поделиться» в Safari.
